# Security Policy

This is a private, internally-deployed application. If you discover a
security issue, report it directly to the team maintaining this repository
rather than filing a public issue.

## Supported Versions

Security fixes are applied to the `main` branch. Deployments should track
`main` to receive the latest fixes.

## Scope

In scope:

- The application code in this repository (backend, web, deployment
  manifests).

Out of scope:

- Third-party services and integrations (report those to the respective
  vendors).
- Findings that require access to a user's account or device, social
  engineering, or physical attacks.
- Denial-of-service issues caused solely by sending high volumes of traffic.
